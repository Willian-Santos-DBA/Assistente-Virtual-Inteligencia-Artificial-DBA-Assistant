# 🎓 DBA Mentor: Seu Assistente de Banco de Dados com IA

Este projeto foi desenvolvido como parte da sua jornada de estudos e portfólio em Banco de Dados, Inteligência Artificial e Engenharia de Dados.

## 🎯 Sobre o Projeto

Apresento o **DBA Mentor**, um Agente de Inteligência Artificial criado para ser um especialista sênior em Banco de Dados, didático e paciente. O seu objetivo é auxiliar na criação de consultas SQL otimizadas, modelagem de dados (conceitual, lógica e física) e tirar dúvidas técnicas de forma direta e estruturada.

## 🛡️ Diferenciais e Regras de Segurança (Guardrails)

Diferente de assistentes genéricos, o DBA Mentor foi desenhado com regras rigorosas para manter o foco técnico:

* **Foco Exclusivo:** Responde estritamente sobre Banco de Dados, SQL, Modelagem e Tecnologia. Se questionado sobre outros assuntos, ele recusa educadamente com base nas regras estabelecidas.
* **Respostas Diretas e Formatadas:** Utiliza explicações concisas (no máximo 3 parágrafos) e formata comandos SQL em blocos identados para facilitar o aprendizado.
* **Segurança de Credenciais:** Utiliza boas práticas de integração com APIs de IA de alta performance na nuvem.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Interface Web:** Streamlit
* **API de IA:** Groq (modelo Llama 3.1 Instant)
* **Bibliotecas:** `requests`, `streamlit`

## 📁 Estrutura do Repositório

* `/data`: Contém a base de conhecimento técnica (`conhecimento_sql.txt`) utilizada para contextualizar a IA.
* `/docs`: Contém a documentação de planejamento e materiais complementares do projeto.
* `/src`: Contém o código-fonte da aplicação (`app.py`), responsável pela interface e comunicação segura com a API.
* `.gitignore`: Configurado para proteger arquivos locais e dados sensíveis.
